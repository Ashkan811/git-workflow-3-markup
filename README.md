# Food Website — Team Git Workflow

სასწავლო გუნდური პროექტი Git-ისა და GitHub-ის სამუშაო პროცესის პრაქტიკისთვის. პროექტის მიზანია არა მხოლოდ Food Website-ის მარკაპზე მუშაობა, არამედ branch-ების მართვა, გასაგები Commit-ების შექმნა, Pull Request-ების გახსნა, თანაკურსელების Code Review და უკუკავშირის საფუძველზე კოდის გაუმჯობესება.

## გუნდური მუშაობის მთავარი წესები

- არ იმუშაო პირდაპირ `main` branch-ში.
- ცვლილებები შეასრულე შენს Fork-ში, ცალკე სამუშაო branch-ზე.
- გახსენი Pull Request შენს მიერ განსაზღვრულ სტუდენტის branch-ისკენ.
- PR-ის ბმული გააზიარე გუნდის საკომუნიკაციო არხში და კონკრეტულად სთხოვე თანაკურსელს review.
- ყველა PR უნდა გაიაროს Code Review და ლექტორის განხილვა.
- მხოლოდ ლექტორი აკეთებს საბოლოო Merge-ს ორიგინალ რეპოზიტორიაში.
